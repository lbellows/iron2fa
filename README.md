# Iron2FA

An offline two-factor authenticator (TOTP and Steam Guard) for Android, with a
Linux desktop build of the same code. Written with Expo (TypeScript).

- **No permissions.** The Android app requests none — no network, no camera.
- **Imports from Proton Authenticator.** It reads Proton's export file, plain or
  password-protected. Its own backups are a separate format that keeps every
  account exactly as held; Proton cannot read them.
- **Encrypted at rest.** AES-256-GCM. On Android the key lives in the Android
  Keystore; on the desktop it is derived from a passphrase with Argon2id.

## Install

Android: add the F-Droid repository at <https://lbellows.github.io/fdroid/>, or
take an APK from [Releases](https://github.com/lbellows/iron2fa/releases).

Desktop (Linux, needs a system Electron — `electron42` on Arch/Artix):

```bash
npm ci
npm run desktop:build     # web bundle into desktop/dist
npm run desktop           # electron42 desktop
```

The vault is kept in Electron's profile, `~/.config/Iron2FA`. The window is
served from a private `app://` scheme and every other request is refused.

## Moving accounts

In Proton Authenticator: Settings → Export. In Iron2FA: Import / Export →
Choose file. Accounts already present are skipped, so importing twice is
harmless. Counter-based (HOTP) entries are not supported and are reported by
name.

To copy accounts from phone to desktop, export on one (set a password) and
import on the other.

## Development

```bash
npm test            # OTP vectors (RFC 6238, Steam), both file formats, the vault
npm run typecheck
npm run web         # the app in a browser
```

`src/core/` is platform-free: `otp.ts` (codes and `otpauth://` parsing),
`backup.ts` (Iron2FA's backup file), `proton.ts` (reading Proton's export),
`crypto.ts` (AES-GCM, Argon2id). The Proton tests build their encrypted fixture
with Node's OpenSSL bindings rather than the app's own libraries, so the two
implementations check each other; they need Node 24.7+.

`android/` is committed and generated by `npm run prebuild`; CI fails if it
drifts from `app.json`. Releases: see [FDROID.md](FDROID.md).
